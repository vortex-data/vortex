# User Guides

Vortex has an integration with
[DuckDB](https://duckdb.org),
[Apache Datafusion](https://datafusion.apache.org),
[Pandas](https://pandas.pydata.org),
[Polars](https://pola.rs),
[Ray](https://ray.io),
and [Apache Spark](https://spark.apache.org).
There is Python support via [vortex-python](./vortex-python.md),
including [pyarrow](https://arrow.apache.org/docs/python/index.html).
Work is in progress for
[Iceberg](https://lists.apache.org/thread/pb66o8gk8nqc6yormfld7pkt6rdfkvh7)
and [cuDF](https://github.com/NVIDIA/cudf/pull/24289).
