# References

Vortex is inspired by and--in some cases--directly based upon the existing, excellent work of many researchers and
OSS developers. This page serves as a reference to the work that has influenced Vortex (and so we don't keep asking
one another to send links to the same papers over and over again).

## Compression & Encodings

* [The FastLanes Compression Layout: Decoding > 100 Billion Integers per Second with Scalar
  Code](https://doi.org/10.14778/3598581.3598587) — Afroozeh, Boncz. PVLDB 16(9), 2023.
* [Accelerating GPU Data Processing using FastLanes
  Compression](https://doi.org/10.1145/3662010.3663450) — Afroozeh, Felius, Boncz. DaMoN 2024.
* [ALP: Adaptive Lossless floating-Point Compression](https://doi.org/10.1145/3626717) —
  Afroozeh, Kuffo, Boncz. Proc. ACM Manag. Data 1(4), 2023.
* [FSST: fast random access string compression](https://doi.org/10.14778/3407790.3407851) —
  Boncz, Neumann, Leis. PVLDB 13(12), 2020.
